### 典型用例
```plaintext
【现代→文言】
输入： "孔子说:做到恭顺端肃忠心诚信,就可以了。"
输出： "子曰：恭肃忠信可也。"

【文言→现代】
输入： "知之为知之，不知为不知，是知也"
输出： "知道就是知道，不知道就是不知道，这才是真正的智慧"
