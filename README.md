# 古言今译
## 项目介绍
- 本项目是基于[bert4keras](https://github.com/bojone/bert4keras)实现的文言文-现代文翻译模型。具体使用了基于掩码自注意力机制的[UNILM(Li al., 2019)](https://arxiv.org/abs/1905.03197)预训练模型作为翻译系统的backbone。实现文言文-现代文的双向翻译,基于blue和余弦相似度的评分体系。
- **数据集：** **小牛翻译（东北大学NLP实验室）在2022年2月开源了一个大规模(接近1000K数据量)的句子级文言文-现代文平行语料，一共有967257个句对，地址在[文言文（古文）-现代文平行语料](https://github.com/NiuTrans/Classical-Modern)** ,本项目采用该数据集依据train:val:test=8:1:1划分用于模型的训练、评估、测试

## 翻译示例

### 现代文 → 古文

```
原句: 伍员逃亡的时候，对申包胥说：我一定要颠覆楚国。
参考翻译: 其亡也，谓申包胥曰：我必复楚国。
翻译结果: 伍员之亡也，谓申包胥曰：吾必覆楚。
```

```
原句: 陆康从小仕于郡，以义烈著称，刺史臧举他茂才，任为高成县令。
参考翻译: 康少仕郡，以义烈称，刺史臧旻举为茂才，除高成令。
翻译结果: 康少仕郡，以义烈著称，刺史臧举茂才，除高成令。
```

```
原句: 太平元年，吕岱九十六岁去世，儿子吕凯继承爵位。
参考翻译: 太平元年，年九十六卒，子凯嗣。
翻译结果: 太平元年，年九十六薨，子凯嗣。
```

### 古文 → 现代文

```
原句: 帝称善，赐名马一、钱十万、衣一称。
参考翻译: 太宗说好，赐给他名马一匹、钱十万、衣服一套。
翻译结果: 皇帝认为很好，赐给他名马一匹、钱十万、衣服一套。
```

```
原句: 上纳其言，仍赐诏褒之。
参考翻译: 后晋高祖采纳了他的意见，仍然赐予褒奖的诏书。
翻译结果: 皇上采纳了他的意见，并赐诏褒奖他。
```

```
原句: 勇对曰；今中国置州牧者，以禁郡县奸猾盗贼也。
参考翻译: 班勇回答说：如今汉朝设置州牧，是为了禁止郡县的奸人盗匪。
翻译结果: 班勇回答说：现在中国设置州牧，是为了禁止郡县奸猾盗贼。
```
